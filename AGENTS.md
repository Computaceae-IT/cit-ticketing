# Context and documentation usage

Minimize context usage and token consumption. Do not recursively discover or read
all Markdown files (`*.md`). Before modifying code:

1. Read the AGENTS.md instructions applicable to the path being modified.
2. Read the Markdown documentation explicitly referenced by those applicable
   AGENTS.md files.
3. Read additional Markdown documentation in the directly concerned directory
   only when its name or content is clearly relevant to the current task, files,
   or feature being modified.
4. Do not scan or read unrelated documentation. Prefer targeted file reads and
   searches over loading large documentation files in full.

Preserve and follow all other applicable AGENTS.md instructions that do not
conflict with this rule.
